## Vector DB가 없어서 떨어지는 부분

현재 주요 기능이 막히지는 않습니다. 검사 검색, 문서·첨부 검색, OCR, 출처 검증, 개인결과, 상담·피드백은 모두 로컬 RDB만으로 작동합니다.

| 영역 | 현재 상태 | Vector DB가 없을 때 한계 |
|---|---|---|
| 정확한 검사명·코드 검색 | 잘 동작 | 거의 없음 |
| 정해진 데모 질문 | 잘 동작 | 평가셋 17/17 통과 |
| 표현이 다른 질문 | 취약 | 문서와 같은 단어가 없으면 관련 내용을 놓침 |
| 동의어·의학적 유사어 | 취약 | 등록된 별칭이 없으면 검색률 저하 |
| 긴 OCR 문서 검색 | 제한적 | 키워드가 포함된 청크만 최대 500개 먼저 가져와 순위를 계산 |
| 영문↔한글·약어 검색 | 제한적 | 데이터에 양쪽 표현이 등록되어 있어야 함 |
| 관련 문서 추천 | 사실상 없음 | 의미가 비슷한 문서를 자동으로 묶기 어려움 |
| 데이터 증가 시 성능 | 점차 저하 | 다수 테이블과 본문을 부분문자열로 탐색 |

예를 들어 문서에는 `휴일 검사일정 변경`이라고 적혀 있는데 사용자가 `연휴 때 검체 접수 가능한가요?`라고 질문하면, 공통 키워드가 부족해서 현재 RDB 검색은 놓칠 수 있습니다. Vector 검색은 이런 의미상 유사 질문에 강합니다.

다만 지금 `OPENAI_VECTOR_STORE_ID`만 설정한다고 바로 완성되는 상태는 아닙니다.
