# 검증 산출물

이 디렉터리는 실행 코드가 아닌 화면 검증 증거를 보관한다. 빌드 입력으로 사용하지 않는다.

- `submission-audit/`: 제출 시나리오 검증 화면.
- `readability-qa/`: 챗봇 답변 가독성 검증 화면.
- 판정과 비교 기준은 [기술 부록](../docs/appendices/README.md)에 기록한다.
- 새 검증은 목적 또는 날짜별 하위 디렉터리에 보관한다. 중간 결과는 최종 보고서와의 연결을 확인한 뒤 정리한다.
- 기존 증거 이미지와 `chat_logs/` 대화 기록은 실행 파일과 구분된 보관 자료이므로 일괄 삭제하지 않는다.
