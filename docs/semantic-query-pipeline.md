# Gemini 검색 전 질문 해석

2026-09-13 적용. 로컬 Python/FastAPI의 Gemini 경로에 적용한다.

## 처리 순서

1. 기존 입력 규칙 검사 후, 서버가 현재 질문의 코드 후보를 추출한다. 한국어 조사는 코드 경계로 허용한다.
2. Gemini가 질문·대화·직전 표시 검사 목록을 받아 `QueryInterpretation`을 생성한다.
3. 서버가 코드의 원문 존재, 필드 라벨, 이전 검사 참조, 조건의 원문 근거를 검증한다. 라벨 없는 코드는 모델이 코드 종류를 추측하지 않도록 두 코드 필드에서 정확 조회한다.
4. 검사 요청은 코드 정확 일치, 검사명·별칭 정확 일치 또는 정제한 검색어의 키워드 검색으로 처리한다. 코드·검체·방법·소요일 제한과 코드 제외는 결과 제한 전에 적용한다.
5. 검사 답변은 DB 값으로 만든다. 같은 코드의 여러 항목은 목록으로 표시하며, 최대 20건을 표시하고 다음 대화에는 표시된 목록만 전달한다. 요청 필드가 없으면 없다고 표시한다.
6. 문서·결과·상담 등 다른 업무는 기존 근거 검색·답변·인증 정책으로 이어진다. 일반 검사 조회는 Gemini 해석 1회, 다른 업무는 해석과 기존 답변 생성으로 2회 호출한다.

일반 검사명/주제 검색에는 기존 키워드 점수가 남아 있다. 코드 정확 조회에는 가산점을 사용하지 않는다. 주제 검색 결과는 확정 목록이 아닌 후보이며 `answerability=partial`이다. 최단 소요일은 확인 가능한 소요일의 상한 값을 비교한다. 누락된 소요일이 있으면 전체 비교가 완료됐다고 표시하지 않는다.

지원하지 않는 조건은 `unsupported_conditions`로 받고 확인이 어렵다고 안내한다. 이 검출 자체는 모델 해석에 의존하므로 모든 자연어 표현의 정확성을 보장하지 않는다. 추가 표현·복합 조건에 대한 평가가 필요하다. 기존 Gemini 연결 실패 시 선택적 데모 응답 정책은 유지되며, `require_live=true`는 데모 대체를 허용하지 않는다. Gemini 안전 차단은 데모 응답으로 넘어가지 않는다.

## 검증

- 백엔드 테스트: 169개 통과. 기존 테스트와 코드 경계·필드 종류·검체별 항목·제외·소요일·이전 결과·없는 코드·인증·안전 차단 검증 포함.
- 기존 감사 표본 61개 급여코드 × 6개 표현: 서버 검증·조회 366/366 통과. 이전의 Hit@10보다 엄격하게 해당 코드의 정답 목록 전체 일치를 검사했다. **Gemini 해석을 제공한 오프라인 검증이며, 366회 실호출 결과가 아니다.**
- 없는 급여코드 20개: 20/20 빈 결과.
- Gemini 실제 호출: 11/11 통과. D517205KZ 여섯 표현, 소요일·급여코드 후속 질문, 추가 문장 표현, 없는 코드, 불일치 검체 조건, 코드 제외를 검사했다. 전체 모델 정확도로 일반화할 수 없는 소규모 확인이다.
- 로컬 HTTP API에서도 `급여코드 D517205KZ로 검사 찾아줘`가 Gemini 모드와 `test:16290:510` 근거를 반환했다.

처음 실호출에서 모델이 라벨 없는 급여코드를 SCL 검사코드로 분류하는 실패가 발견되어, 필드 라벨을 서버에서 검증하도록 수정한 뒤 재검증했다. 공개 데이터의 `D156100KZetc`처럼 코드 뒤에 붙은 주석도 코드 조회용 정규화에서 처리한다.

재현 스크립트: `scripts/evaluate_query_interpretation.py`. 원본 SQLite를 읽기 전용으로 열어 별도 평가 DB로 복사한다. `--baseline`은 기존 감사 결과 JSON을 받아 오프라인 비교하며, `--live`를 명시해야 현재 로컬 Gemini 키로 호출한다. 키는 출력하지 않는다. 결과는 기본 `tmp/semantic-query-eval/offline.json`, `live.json`에 저장한다.

```powershell
$env:PYTHONPATH='backend'
.venv/Scripts/python.exe -m pytest -q backend/tests
.venv/Scripts/python.exe scripts/evaluate_query_interpretation.py --baseline tmp/search-score-audit-20260913/results.json
.venv/Scripts/python.exe scripts/evaluate_query_interpretation.py --live
```

로컬 화면은 Vite 실행 환경에 `VITE_CHAT_API_URL=http://127.0.0.1:8000/api/chat`을 지정해 FastAPI로 연결한다. Sites Worker의 배포용 검색 경로는 이번 Python 변경의 적용 대상이 아니다.
