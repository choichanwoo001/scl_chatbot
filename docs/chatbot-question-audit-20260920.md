## 우선 개선 항목

1. **자연어 검사 개념 사전**: 간 검사→ALT/AST/γ-GTP, 갑상선→TSH/Free T4/T3, 에이엘티→ALT 같은 동의어·발음·일상어 매핑.
2. **비교 답변 전용 형식**: 공통점은 한 줄, 차이점만 표나 짧은 목록으로 출력하고 장문 원문은 접거나 상세 링크로 분리.
3. **복합·부정 조건 처리**: 검사명+검체, 토요일, 혈액 제외/소변, 소요일 등의 AND/NOT 조건을 구조화.
4. **문맥 후보 유지**: 단일 검사와 후보 목록을 명확히 구분하고 후속 대명사·순서·최단 소요일 필터를 안정적으로 적용.
5. **사이트 정보 라우팅**: 의뢰방법, 지점 주소/전화번호, 최근 공문을 각각 route/location/document 데이터로 직접 연결.
6. **의료 해석 안전 응답**: 결과 조회와 결과 해석을 구분하고, 해석 요청에는 임의 판단 제한과 의료진/상담 경로를 안내.
