# 한계와 운영 전환 로드맵

기준일: 2026-08-23

## 1. 현재 판정

공개 검사·문서 검색과 안전 흐름을 보여주는 기업 시연에는 사용할 수 있다. 실제 환자 결과를
처리하는 공개 운영 서비스로는 아직 승인할 수 없다.

## 2. 현재 한계

| 영역 | 현재 상태 | 영향 |
|---|---|---|
| 데이터 권위 | 공개 홈페이지 동기화 | 기관 공식 검사 DB와 차이 가능 |
| 개인 결과 | Provider 코드·계약만 완료 | 실제 계정 E2E 불가 |
| Vector 검색 | 코드 완료, Store 미생성 | 의미 검색 원격 품질 미측정 |
| FAQ | 게시 0건 | 운영 FAQ 학습 효과 없음 |
| 세션 | 단일 프로세스 메모리 | 재시작·다중 인스턴스 공유 불가 |
| 상담·피드백 보존 | 암호화 저장, 기간 미정 | 삭제·감사 정책 필요 |
| 관측성 | 상태 API·CLI | 중앙 로그·메트릭·알림 없음 |
| 남용 방지 | 길이·입력 정책 | rate limit·WAF 없음 |
| UI | 데스크톱 전용 | 작은 화면 지원 없음 |
| 접근성 | 코드 기반 기본 점검 | 보조기기 실사용 검증 없음 |
| 성능·비용 | 기능 평가 중심 | 부하·지연·월 비용 미측정 |

## 3. P0 — 운영 전 필수

1. 기관 공식 검사 DB 또는 승인된 읽기 API 연결
2. 개인 결과 Gateway URL·계약·mTLS·샌드박스 계정 확보
3. 개인정보 영향평가, 법무·의료·보안 검토
4. 상담·피드백 보존기간, 삭제·열람·감사 절차 확정
5. Secret Manager, 키 회전과 인증서 만료 관리
6. rate limit, WAF, 중앙 감사 로그와 경보
7. PostgreSQL·공유 세션 저장소와 백업·복구 훈련
8. p95 지연·오류율·처리량·비용 기준 수립
9. 장애 대응 담당자와 운영 SLA 확정

## 4. P1 — 검색·답변 품질

1. 20건 Vector 카나리 색인과 shadow 평가
2. 승인 후 3,640건 전체 증분 색인
3. 최소 50개 의미 검색 평가셋과 실패 질의 분류
4. 사용자 피드백을 통한 FAQ 검토·게시 운영
5. 모델·프롬프트 버전별 회귀 평가 자동화
6. 데이터 freshness와 원문 변경 경보
7. 낮은 신뢰도 답변의 상담 전환 기준 정량화

## 5. P2 — 제품 확장

1. 승인된 관리자 검토 화면
2. 상담 티켓 시스템 연동
3. 배포 환경별 feature flag 관리
4. 접근성 전문 검수와 키보드·스크린리더 개선
5. 필요성이 확인된 경우에만 별도 작은 화면 경험 설계
6. 스트리밍·다국어·음성 등 추가 채널 검토

## 6. 운영 승인 게이트

아래 조건을 모두 충족하기 전에는 개인 결과 운영을 활성화하지 않는다.

- 기관 Gateway 계약 테스트 통과
- 실제 사용자 인증정보가 OpenAI·로그·DB에 남지 않음을 검증
- 권한·만료·로그아웃·오류 케이스 E2E 통과
- 개인정보·보안·법무 승인 완료
- 백업 복구와 장애 전환 훈련 완료
- 운영 SLA·담당자·연락체계 확정

Vector 검색은 별도 게이트를 적용한다.

- 카나리·shadow 평가 기준 통과
- 색인 커버리지 99% 이상
- 실패 매핑과 stale active 0건
- 기존 키워드 검색 대비 품질 저하 없음
- 비용 한도와 삭제 책임자 승인

## 7. 제출 이후 권장 순서

```text
공식 데이터 계약
→ 보안·개인정보 승인
→ 결과 Gateway 샌드박스
→ 관측성·rate limit·공유 세션
→ Vector 카나리·shadow
→ 제한된 내부 파일럿
→ 운영 승인
```

과제 제출 시에는 구현 완료와 운영 준비 완료를 구분해 설명한다. 현재는 공개 정보 시연 범위가
완료된 상태이며, P0 항목은 기관 협업이 필요한 운영 전환 작업이다.
