# SCL 챗봇 문제 원인 및 개선 결과

- 작업 범위: 백엔드 질의 해석·검색·응답 생성
- 제외 범위: UI/프런트엔드
- 기준 테스트: `docs/chatbot-question-audit-20260920.md`

## 원인 분석과 해결

| 문제군 | 원인 | 적용한 해결 |
|---|---|---|
| 간 검사·갑상선·에이엘티 | 일상 표현과 표준 검사명의 연결 규칙이 없음 | 간 기능, 갑상선, 한글 발음 표현을 검증된 검사명 집합으로 정규화 |
| Serum·소변·당일·토요일 | 모델이 복합 조건 일부를 누락하거나 지원 불가로 분류 | 검체·소요일·요일을 결정 규칙으로 추출하고 검색 단계에서 AND 필터 적용 |
| ALT와 AST 추가 조회 | 영문 검사명 뒤 한국어 조사를 경계로 인식하지 못하고 비교로 오분류 | ASCII 기준 검사명 인식 및 명시적 비교 표현이 있을 때만 비교 응답 사용 |
| HPV 용기 | 공개 데이터의 용기 세부 키와 응답 필드명이 다름 | 용기 첨가제·주요 검사항목·주의사항을 실제 용기 설명으로 조합 |
| 두 ALT 비교 | 전체 공개 원문을 그대로 출력 | 공통점과 실제 차이점만 짧게 분리하고 장문 원문 제외 |
| 의뢰방법·지점 | 일반 문서 생성 경로에 의존 | route/location 공개 데이터를 직접 검색하는 결정 경로 추가 |
| 최근 신규검사 | 본문 관련도만 사용해 오래되거나 무관한 문서가 우선됨 | 제목에 ‘신규’와 ‘검사’가 모두 있는 공식 공문만 날짜순 정렬 |
| 최신 공문 지연 | 단순 문서 조회도 외부 의미검색을 기다림 | 신뢰된 로컬 공개 데이터 색인만 사용하는 검색 경로 추가 |
| 결과 정상 여부 해석 | 결과 조회와 의료 해석 요청을 혼동 | 임의 진단을 차단하고 의료진/상담 안내 및 인계 상태 반환 |

## 재검증 결과

초기 실패·부분 통과 18개 질문을 실제 API로 다시 확인했다.

| 질문 번호 | 재검증 결과 |
|---|---|
| 1, 2, 10, 20, 21, 25 | 간 기능·갑상선 관련 표준 검사 후보를 반환 |
| 4, 23 | HPV 검체·용기 첨가제/주요 항목·방법·소요일을 반환 |
| 9 | ALT와 AST의 일반/특검 항목을 함께 반환 |
| 14, 18, 22 | ALT+Serum, 에이엘티, 소변 대체 조건을 정상 처리 |
| 27 | 공통점과 검사요일·보존방법·주의사항 차이만 요약 |
| 29 | 검사 의뢰방법 메뉴와 정확한 공개 링크 반환 |
| 30 | 2026-08-18 최신 신규검사 공문을 최우선 반환 |
| 33, 34 | 대구·제주 주소와 전화번호 반환 |
| 36 | 의료 해석 제한과 담당 의료진/상담 경로 안내 |

## 자동 검증

- 백엔드 전체 테스트: 167개 통과
- 변경 파일 정적 검사: 통과
- 기존 40개 평가 기준 환산: 80/80점

기존 통과 항목은 백엔드 전체 회귀 테스트로 확인했고, 링크 클릭·채팅 복귀 등 UI 항목은 변경하지 않았다.
