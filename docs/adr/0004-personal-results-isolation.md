# ADR-0004: 개인 결과 Provider 격리

- 상태: Accepted
- 결정일: 2026-08-23

## 배경

개인 결과 인증정보와 검사결과를 일반 채팅·LLM 경로에 섞으면 불필요한 외부 전송과 저장 위험이
생긴다. 공개 홈페이지 로그인 자동화는 공식 운영 계약을 보장하지 않는다.

## 결정

개인 결과는 별도 Provider 인터페이스와 HTTPS/mTLS Gateway 계약으로 격리한다. 인증정보와 결과는
OpenAI에 전달하거나 로컬 DB에 저장하지 않으며 Provider가 미설정이면 명시적으로 실패한다.

## 결과

- 공개 채팅과 민감 업무의 신뢰 경계가 분명해진다.
- 기관이 승인한 Gateway만 교체 연결할 수 있다.
- mock은 자동 테스트에만 사용할 수 있다.
- 실제 운영 완료에는 기관 계약·샌드박스·보안 승인이 필요하다.
