# ADR-0003: Structured Outputs 기반 라우팅

- 상태: Accepted
- 결정일: 2026-08-23

## 배경

자유 텍스트 응답만 사용하면 검사 검색, 결과조회, 문서, 계정과 상담 흐름을 안정적으로 분기하고
서버 정책을 강제하기 어렵다.

## 결정

OpenAI Responses API의 Structured Output으로 도메인, 하위 의도, 요청 행동, 후보 식별자와 정책
플래그를 받는다. Pydantic과 서버 정책으로 조합을 검증하고 실패 시 한 번 교정 재시도한다.

## 결과

- UI 카드·인증 폼·상담 폼을 결정적으로 선택할 수 있다.
- 도메인과 하위 의도의 잘못된 조합을 거부한다.
- 모델은 라우팅을 제안하지만 최종 권한은 서버에 남는다.
- 스키마 변경 시 평가셋과 하위 호환성을 함께 관리해야 한다.
