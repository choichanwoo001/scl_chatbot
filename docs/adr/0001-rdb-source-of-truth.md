# ADR-0001: RDB를 최종 신뢰 원본으로 사용

- 상태: Accepted
- 결정일: 2026-08-23

## 배경

LLM과 의미 검색은 자연어 표현을 처리하는 데 유리하지만 검사 코드, 용기, 일정, 공개 상태와
출처 존재 여부를 보장하지 못한다.

## 결정

검사·위치·메뉴·공개문서의 최종 사실은 로컬 RDB에서 조회한다. 모델과 Vector Store가 반환한
식별자는 서버가 RDB에서 다시 해석할 수 있을 때만 답변에 사용한다.

## 결과

- 환각된 검사 코드와 출처를 차단할 수 있다.
- 데이터 비활성화가 답변에 즉시 반영된다.
- 모델·Vector Provider를 바꿔도 신뢰 경계가 유지된다.
- RDB 동기화 품질과 freshness가 전체 답변 품질의 핵심 운영 책임이 된다.
